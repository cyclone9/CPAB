## این نسخه چیست

نسخهٔ `0.1.0` فقط رابط کاربری است: پنجرهٔ کوچک نوار ابزار و صفحهٔ تنظیمات، به فارسی و انگلیسی، با پوستهٔ تیره و روشن. می‌توانید افزونه را روی یک سایت متوقف کنید، کلید اصلی را روشن و خاموش کنید و زبان و رنگ‌بندی را عوض کنید. این انتخاب‌ها در مرورگر خودتان ذخیره می‌شوند.

مسدود کردن بعد از این می‌آید. تا آن زمان افزونه به هیچ صفحه‌ای دست نمی‌زند و گزینه‌های پاپ‌آپ‌ها، کادرهای مزاحم، سایت‌های مضر و سایت‌های بزرگسال با برچسب «در نسخه‌های بعدی» غیرفعال هستند.

## بارگذاری در کروم

به Node.js نسخهٔ ۲۴ یا بالاتر نیاز دارید.

<div dir="ltr">

```
npm test
npm run build
```

</div>

بعد `chrome://extensions` را باز کنید، حالت Developer mode را روشن کنید، Load unpacked را بزنید و پوشهٔ `dist/` را انتخاب کنید.
