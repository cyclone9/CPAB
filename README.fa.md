## این نسخه چیست

نسخهٔ `0.1.6` تبلیغ‌ها، ردیاب‌ها و شبکه‌های تبلیغاتی ایرانی را با قانون‌هایی مسدود می‌کند که از EasyList، EasyPrivacy، AdGuard Base و PersianBlocker تبدیل شده‌اند. نسخهٔ `0.1.2` دامنهٔ کامل و بخشی از نشانی را بررسی می‌کرد؛ این نسخه قانون‌ها و استثناهای مربوط به یک سایت مشخص را هم تبدیل می‌کند، پس صفحه‌های کمتری خراب می‌شوند. مبدل هنوز کامل نیست: قانون‌های پاپ‌آپ، پنهان‌سازی و عبارت منظم هنوز تبدیل نمی‌شوند. به همین دلیل بعضی تبلیغ‌ها هنوز دیده می‌شوند و گاهی صفحه‌ای خراب می‌شود، مثلاً درون قاب‌های تعبیه‌شده. در این حالت افزونه را از پنجرهٔ کوچک نوار ابزار روی همان سایت متوقف کنید.

کلید اصلی و کلید هر دسته قانون‌ها را روشن و خاموش می‌کنند. نماد نوار ابزار و پنجرهٔ کوچک نشان می‌دهند در صفحهٔ فعلی چند مورد مسدود شده است. پنجرهٔ کوچک تعداد را برای هر دسته جدا نشان می‌دهد و سایت‌هایی را که خودتان مسدود کرده‌اید در خطی به نام «سایت‌های شما» می‌شمارد. در تنظیمات می‌توانید سایت‌های مسدودشدهٔ خودتان را اضافه کنید تا آن‌ها و زیردامنه‌هایشان همه‌جا مسدود شوند. تنظیمات تعداد قانون‌ها و تاریخ هر فهرست را نشان می‌دهد و بخش «درباره» سازندگان فهرست‌ها را معرفی می‌کند. زبان و رنگ‌بندی را هم می‌توانید عوض کنید. این انتخاب‌ها در مرورگر خودتان ذخیره می‌شوند.

گزینه‌های پاپ‌آپ‌ها، کادرهای مزاحم، سایت‌های مضر و سایت‌های بزرگسال با برچسب «در نسخه‌های بعدی» غیرفعال هستند.

## بارگذاری در کروم

به Node.js نسخهٔ ۲۴ یا بالاتر نیاز دارید.

<div dir="ltr">

```
npm test
npm run lists
npm run build
```

</div>

ساختن افزونه به فهرست‌ها نیاز دارد. دستور `npm run lists` آن‌ها را روی دستگاه شما دریافت می‌کند و فهرست ایران هم از همین راه وارد می‌شود.

بعد `chrome://extensions` را باز کنید، حالت Developer mode را روشن کنید، Load unpacked را بزنید و پوشهٔ `dist/` را انتخاب کنید.
